# Research and Evidence Prompt Kit

## Query planning

Given a brief, create short composable queries covering foundations, primary sources, implementation, trade-offs, failure modes, security, governance, counterarguments, and date/version checks. State the source type and decision affected by each query.

## Evidence extraction

For each meaningful claim, return the claim, exact passage or precise paraphrase, URL, source date/version, evidence type, confidence, limitations, and contradictions. Separate direct evidence from interpretation.

## Synthesis

Produce a structured note with research question, system map, evidence labels, mechanisms, failure modes, real-world practice, open questions, experiments, and epistemic update.
