# Person and Capability Prompt Kit

Model the Person Atlas as an evidence-backed graph, not a static résumé.

Capture:

- interests and motivations;
- experience and demonstrated behavior;
- existing capabilities;
- constraints and access;
- learning preferences;
- aspirations and exclusions;
- evidence, confidence, recency, and counter-evidence.

For each opportunity-person intersection, explain existing assets, required capabilities, missing capabilities, evidence supporting the match, and the smallest project that could generate new evidence.
