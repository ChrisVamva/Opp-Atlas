# Prompts and Resources

This folder contains reusable methods, prompts, agent roles, and reference material for operating Opp Atlas.

## Operating sequence

`Orient → Observe → Expand → Research → Recombine → Formulate → Stress-test → Experiment → Decide → Update`

## Design rule

Prompts are operational interfaces. Every production prompt should define its purpose, inputs, process, output schema, evidence requirements, failure modes, and handoff.
