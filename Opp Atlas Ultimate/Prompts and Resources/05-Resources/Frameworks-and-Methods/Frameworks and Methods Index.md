# Frameworks and Methods Index

## Core methods

- Problem mining from friction, complaints, workarounds, job descriptions, and obligations.
- Workflow archaeology across inputs, decisions, handoffs, records, and verification.
- Capability arbitrage and person–opportunity intersection.
- Technology-discontinuity analysis: new capability → changed cost structure → new problem space.
- Cross-domain transfer of mechanisms such as observability, version control, routing, simulation, and quality control.
- Second-generation brainstorming after research.

## Epistemic progression

`Observation → Problem Candidate → Problem Graph → Opportunity Space → Hypothesis → Experiment`
