# Data and Tool Resources Index

## Data sources for opportunity discovery

- complaints, reviews, forums, support questions, and troubleshooting guides;
- job descriptions and job advertisements;
- procurement specifications and regulatory documents;
- maintenance logs, incident reports, feature requests, and known issues;
- observed workflows, interviews, and direct work evidence.

## Tool roles

- search and source discovery;
- evidence extraction and citation capture;
- Markdown and Obsidian delivery;
- DuckDB storage and querying;
- pandas analysis;
- graph or table visualization;
- experiment and decision logging.

Every tool should have a visible purpose, permission model, and failure mode.
