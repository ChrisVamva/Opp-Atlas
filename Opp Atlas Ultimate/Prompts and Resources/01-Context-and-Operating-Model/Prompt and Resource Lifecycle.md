# Prompt and Resource Lifecycle

## Lifecycle

1. **Discover** — identify a recurring task or reasoning need.
2. **Specify** — define inputs, role, output, quality bar, and handoff.
3. **Test** — run against complete and deliberately incomplete evidence.
4. **Critique** — inspect hallucination, omission, contradiction, and premature convergence.
5. **Version** — record changes and the reason for each change.
6. **Deploy** — connect the prompt to a repeatable workflow.
7. **Measure** — track usefulness, evidence quality, effort, and failure patterns.
8. **Retire or revise** — update the prompt when the system or task changes.

## Prompt contract

Every production prompt should state: purpose, context, inputs, procedure, output schema, epistemic rules, failure modes, and next handoff.
