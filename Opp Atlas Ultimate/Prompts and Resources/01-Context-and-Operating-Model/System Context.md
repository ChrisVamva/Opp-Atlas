# System Context

Opp Atlas is an evidence-backed opportunity database. It models problems, industries, workflows, technologies, capabilities, constraints, opportunities, sources, claims, experiments, and decisions.

The prompts in this folder are not generic business brainstorming tools. They support a system that:

- expands the opportunity space before converging;
- treats observations as raw data;
- separates facts, claims, inferences, assumptions, and unknowns;
- preserves provenance;
- turns uncertainty into research questions and experiments;
- connects opportunity-world data with the Person Atlas;
- updates the database after each meaningful result.

The desired output is not merely prose. It is a structured record that can enter the Opp Atlas knowledge and data layers.
