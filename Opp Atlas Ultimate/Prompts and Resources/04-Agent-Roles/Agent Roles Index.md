# Agent Roles Index

Opp Atlas uses specialized roles with explicit handoffs.

- [[Discovery Agent]] — expands and mutates opportunity spaces.
- [[Research Agent]] — plans retrieval and records evidence.
- [[Evaluation Agent]] — compares candidates and attacks assumptions.
- [[Capability and Learning Agent]] — maps intersections to capability gaps and learning paths.
- [[Synthesis and Decision Agent]] — creates decision-ready records.

The sequence is:

`Discovery → Research → Synthesis → Strategic Optimization → Validation Design → Execution / Learning`

No role should silently perform another role's work without recording the handoff.
