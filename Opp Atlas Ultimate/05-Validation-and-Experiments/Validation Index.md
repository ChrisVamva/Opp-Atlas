# Validation Index

## Purpose

Experiments convert opportunity uncertainty into evidence. They are not implementation plans and not proof of success.

## Experiment record

Every experiment states:

- target opportunity;
- hypothesis;
- assumption under test;
- method;
- smallest credible sample;
- success signal;
- kill signal;
- cost and time;
- result;
- decision impact.

## Validation sequence

`Assumption → Test → Observation → Result → Interpretation → Decision → Database update`

## Experiment classes

- problem occurrence;
- problem intensity;
- access and distribution;
- willingness to pay;
- solution usefulness;
- capability acquisition;
- technical feasibility;
- workflow adoption.
