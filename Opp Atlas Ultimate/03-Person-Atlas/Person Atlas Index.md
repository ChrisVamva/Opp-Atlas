# Person Atlas Index

The Person Atlas is the personal graph that makes Opp Atlas more than a generic opportunity catalogue.

## Model

`Person → interests / experience / capabilities / constraints / preferences / learning history`

## Evidence distinction

- **Declared** — the person says it.
- **Observed** — behavior or work demonstrates it.
- **External** — a source or evaluator supports it.
- **Inferred** — the system proposes it; it remains uncertain until tested.

## Connected outputs

- career or work hypotheses;
- opportunity-person intersections;
- capability gaps;
- learning programs;
- evidence-producing projects;
- updated capability records.

## Operating rule

Do not treat a profile attribute as stable merely because it appears in a note. Track its evidence, confidence, last observation, and counter-evidence.
