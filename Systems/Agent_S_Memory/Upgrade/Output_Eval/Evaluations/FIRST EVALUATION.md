# Top 3

## 1. Clause Mirror

- Why it survived: Immediate utility, zero dependency, clear output
    
- Stronger because: No infrastructure barrier, fast adoption
    
- Main risk: commoditization via LLM wrappers
    
- Confidence: **High**

- Confidence: **High**

## 3. CourtSight

- Why it survived: Massive unmet demand
    
- Stronger because: replaces expensive human service
    
- Main risk: legal liability + accuracy requirements
    
- Confidence: **Medium**

# Final Winner: Clause Mirror

### Why this is best now

- Fastest path to real usage
    
- No need for ecosystem change
    
- Clear user moment (contracts, terms, agreements)
    

### Why stronger than #2 (Benefit Reclaimer)

- Lower operational complexity
    
- No dependency on fragmented systems
    
- Easier to prototype and validate
    

### Core strength

**Market gap + timing**

# Final Challenge

**Dead Internet Index may be false novelty**

Reason:

- Many credibility scoring / bot detection systems already exist
    
- Hard problem is not detection, but **user trust in the detector**
    
- Risk: becomes another “score layer nobody fully believes”
